# 📌 회고
> - 프로젝트 초기 정확한 구조, 함수 이해 없이 진행하면서 개발 일정이 늦어졌습니다.
> - 하지만 MVC 패턴과 Ajax, gson을 구현하며 앞서 배웠던 것을 총 복습할 수 있는 프로젝트였습니다.

### 🔎 소개 및 목적
 - 일상에서 익숙한 은행 웹 서비스를 직접 구현
 - 해당 프로젝트를 통해 MVC 패턴에 익숙해지고 비동기 정보 교환 기법 습득, MyBatis 활용
### 🔎 개발 기간
2024.06.18 ~ 2024.07.10
### 🔎 사용 언어 및 개발 환경
`Java` `Servlet` `JSP` `JavaScript` `Tomcat` `OracleDB` `MyBatis` `Eclipse` `HTML` `CSS`
